# Идеи и рекомендации по развитию ассистента Infinity: The Game

Этот документ содержит список фичей и улучшений для приложения-помощника Infinity.

---

## 1. ⏱ Отслеживание раундов и структуры хода (Turn & Round Manager)
- [ ] **Счётчик раундов (Round 1 / 2 / 3):** индикация текущего раунда и переключение активного/реактивного хода (Active / Reactive Turn).
- [ ] **Кнопка «End Turn» (Завершить ход):** автоматический сброс потраченных приказов (`isSpent`) для следующего хода и переход к следующему раунду.

## 3. 🎯 Счётчик Победных Очков и Секретные Задачи (VP & Objectives)
- [x] ~~**Счётчик VP (Victory Points):** отслеживание текущих победных очков в партии с удобным управлением (+/-).~~
- [ ] **Генератор / Трекер Classified Objectives:** список и случайная генерация секретных задач (ITS) с отметкой их выполнения.
- [ ] **Отслеживание состояния HVT (High Value Target):** отметки статуса (Designated / Secured / Captured).

---

## 4. 🎲 Дайс-роллер и справочники (Dice & Modifiers)
- [ ] **Встроенный d20 роллер:** бросок от 1 до 5 кубов (Burst), проверка на значение характеристик (BS/WIP/ARM/BTS) с учетом Critical Hits.
- [ ] **Таблицы модификаторов:** дистанции оружия, укрытия (Cover -3 BS, +3 ARM), эффекты камуфляжа и миметизма.

---

## 5. 📱 Интеграция с ростерами (Infinity Army)
- [ ] **Импорт ростера по Army Code / QR:** распарсивание кода из официального Infinity Army для автоматического создания боевых групп и стартового пула приказов.
- [ ] **Трекер состояния юнитов:** учет ран (Wounds/STR) и состояний для каждой модели в группе.

---

## 6. 📖 Справочник правил и состояний (Rules & States Reference)
- [ ] **Карточки состояний:** быстрый просмотр состояний (Isolated, Immobilized, Targeted, Camo) и способов их снятия.
- [ ] **Таблица программ Хакинга:** список программ с дистанциями, модами и объектами применения.

---

## 7. 🛠 Удобство использования за столом (Tabletop QoL)
- [ ] **Keep Screen On:** флаг предотвращения гашения экрана во время игры.
- [ ] **Таймер на ход (Match Clock / Chess Timer):** контроль времени на партии и ходы.
- [ ] **Цветовые темы фракций:** кастомные темы под фракции (PanOceania, Yu Jing, Haqqislam, Nomads, Combined Army, Aleph, Ariadna, O-12).
